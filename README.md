🚌 Trimurti Travels – Booking & Portal Web App
A modern, mobile-responsive single-page web portal designed for Trimurti Travels (Pandharpur – Pune Daily Express). Featuring a royal amber & obsidian dark UI, interactive 16-seater bus seat selector, dynamic two-way route switcher, Google review highlight cards, and instant one-click WhatsApp reservation dispatch.

🌟 Key Features
Warm Royal Theme: Tailored amber/saffron and deep obsidian aesthetic (#f59e0b, #070a12) fitting for Maharashtra highway travel and pilgrim routes.

Interactive Bus Seat Grid:

Visual seat map with driver cabin & entry door orientations.

Dedicated indicators for Available, Selected, and Ladies Priority seats.

Real-time seat updates and estimated fare calculation.

Dynamic Two-Way Route Toggle:

Switch between Pandharpur ➔ Pune and Pune ➔ Pandharpur on the fly.

Automatically populates the correct pickup and drop stops (e.g., Vitthal Mandir Mahadwar, Shivaji Maharaj Chowk, Hadapsar Gadital, Swargate, Katraj, Wakad, etc.).

Google Reviews Showcase (4.1 ★ / 72 Reviews):

Auto-rotating customer testimonial slider showcasing verified passenger feedback (including mentions of Anna Chavan and pilgrimage trips).

Direct Google Maps location link to the Chouphala office near Gajanan Maharaj Math.

1-Click WhatsApp Booking Dispatch:

Pre-formats passenger name, contact number, route, boarding & drop point, travel date, departure slot, and seat number.

Dispatches directly to Trimurti Travels' official contact: +91 96236 56609.

Zero Dependencies / Vanilla Code:

Single standalone HTML file with embedded CSS and modern ES6 JavaScript.

Uses Google Fonts (Plus Jakarta Sans, Space Grotesk) & FontAwesome icons via CDN.
